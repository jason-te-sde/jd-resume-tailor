# Technologies, tools, services and standards a resume bullet might name.
#
# One technology per line: the canonical name, then its aliases, separated by "|". Two names on
# the same line are the same thing to the entity check ("Postgres" in a bullet is supported by
# "PostgreSQL" in a source). A line that starts with "=" is matched case-sensitively, which keeps
# a name that is also an ordinary word ("Go", "Spark", "Flask") from matching the word.
#
# The list is deliberately finite. A name that is not here is still caught when it is CamelCase or
# ALLCAPS, or a capitalised word that appears in no source; this list adds the lower-case and plain
# capitalised names that those rules cannot tell from prose ("kubernetes", "Kafka").
